# Travel map assets

- D3 7.9.0: https://github.com/d3/d3 (ISC; see D3-LICENSE).
- TopoJSON client 3.1.0: https://github.com/topojson/topojson-client (ISC; see TOPOJSON-LICENSE).
- `assets/json/travel-world.json`: world-atlas 2.0.2, countries-110m.json, https://github.com/topojson/world-atlas. Derived from Natural Earth public-domain map data: https://www.naturalearthdata.com/about/terms-of-use/.

The map loads these assets locally. Add future city entries to `_data/travel.yml`; coordinates use latitude and longitude in degrees. An optional `url` is reserved for future photo galleries.
