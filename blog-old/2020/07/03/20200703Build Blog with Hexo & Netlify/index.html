利用Hexo & Netlify建立博客

网站优化

我的博客是基于静态博客平台Hexo的，采用的主题是基于yelee风格的，该主题的作者也是在yilia的基础上进行修改的。

利用Hexo来建站非常的方便简单，这篇文章就来记录一下我的建站过程。

安装Git和Node.js

在安装Hexo前，我们首先需要安装Git与Node.js. 其中Git是我们将本地的网页文件传到Github的工具，而Hexo是基于Node.js编写的。

从官网直接安装即可，安装完后在命令行输入git --version 和 node -v， 如果出现了版本号，则说明安装成功。

安装Hexo

安装好Git和Node.js后，就可以安装Hexo了。
首先进入到你想要安装Hexo的文件夹，右键点击git bash here 打开 git 的控制窗口，然后输入

npm install -g hexo-cli

来安装Hexo。安装完成后可以用hexo -v 来验证是否安装成功。
之后键入hexo init， 就会在当前文件夹生成一个初始化的网站，接着用npm install来安装必要的组件。
网站初始化完成后，输入hexo generate 或hexo g就会生成网页，再输入hexo server或hexo s就可以在本地访问该网页了。打开浏览器访问http://localhost:4000就可以看到初始化的博客网站了。

部署到Github Page

接下来要将本地的文件夹与Github仓库关联起来，打开博客根目录下的_config.yml文件，修改如下配置：

deploy:  
 type: git  
 repo: https://github.com/<username>/<project>  
 branch: master

之后安装hexo-deployer-git

npm install hexo-deployer-git

然后运行 hexo clean && hexo deploy, 查看 username.github.io 网页是否部署成功。

利用Netlify部署网页&设置个人域名

利用Netlify进行网站部署非常的简单，进入netlify官网，关联github仓库即可，按照操作一步步来，可在netlify中直接添加个人域名。
